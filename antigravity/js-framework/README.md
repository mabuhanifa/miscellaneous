# Lightweight Zero-Dependency JS Framework

A minimal (~300 lines) JavaScript framework for building SPAs without build tools.

## Features
- **Virtual DOM**: Efficient diffing and patching.
- **Component System**: Class-based components with state and lifecycle.
- **Router**: Client-side routing with history API.
- **Store**: Centralized state management (Redux-like).

## Quick Start

1. Serve the project directory:
   ```bash
   python3 -m http.server 8000
   ```

2. Open the example app:
   [http://localhost:8000/src/example/index.html](http://localhost:8000/src/example/index.html)
